# Voco 文档

这些指南对应当前桌面应用的实际功能：从 Excel 创建词汇包、按顺序进行词汇会话、使用独立的随机抽取器，以及将旧版 YAML 数据自动迁移到当前 TOML 格式。

## 文档导航

- [快速开始](/docs/getting-started)：从 Excel 工作簿创建词汇包并开始词汇会话。
- [词汇包](/docs/features/vocabulary-management)：分类、排序、工作簿导入和本地存储。
- [词汇会话](/docs/features/classroom-challenge)：词条顺序、显示控制、快捷键和会话状态。
- [随机抽取器](/docs/features/random-picker)：创建标签预设，并设置每个标签重置前可抽取的次数。
- [Excel 导入参考](/docs/reference/import-format)：支持的工作簿格式、工作表选择、列映射和图片处理。
- [旧数据迁移](/docs/migration/from-legacy)：已实现的 YAML 数据启动迁移流程。

文档只描述应用中已实现的行为。对于当前界面不支持的能力，例如导出词汇包或手动迁移/恢复界面，会明确说明限制。
