# Excel 导入参考

当前词汇包向导支持 `.xlsx` 和 `.xls` 工作簿。应用界面不提供 CSV 导入选项。

## 工作簿和工作表

可以通过文件选择器或拖放方式选择工作簿。如果文件包含多个工作表，可在工作表选择器中选择要导入的工作表。预览会显示工作表数据及合并单元格信息。

## 行和列映射

向导会检测前五行中的候选表头行，也提供无表头（从第一行开始）和自定义起始行。原文和译文列为必选映射；原文说明、译文说明及图片列可选。

只有原文和译文都非空的行会被加入，文本首尾空格会被去除。说明从所选列读取；图片列按文本读取，可用于匹配图片资源。

## 图片

导入流程可以按所选工作表和锚定列提取工作簿内嵌图片，也可以加载外部图片文件或文件夹并匹配到词条。外部图片支持 PNG、JPEG、GIF、WebP 和 BMP。请在会话中确认图片显示正常。

## 保存前核对

保存前检查工作表、数据起始行、列映射和预览。原文或译文任一为空的行会被跳过。Voco 不保证保留工作簿格式、公式、批注或所有 Excel 功能。
