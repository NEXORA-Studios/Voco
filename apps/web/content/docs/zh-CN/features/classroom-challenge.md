# 词汇会话

从词汇包卡片启动会话。Voco 按该词汇包的既定顺序逐项展示词条，每次选择下一项时会播放动画。动画是切换效果，不会独立随机选择新词条。要随机排列整组词汇，请将排序方式设为“随机”并重置顺序。

## 会话流程

1. 从主页启动一个词汇包。
2. 按**空格键**或会话按钮开始词条切换动画。
3. 动画停止后查看当前词条，并根据需要显示答案或相关内容。
4. 再按空格键或下一项按钮继续。
5. 完成后，可选择排序方式重新开始，或返回词汇包列表。

会话显示剩余词条数。会话开始时，缺少原文或译文的词条会被排除。

## 显示控制

会话控件可以开关原文、原文说明、译文、译文说明和图片。图片可以显示在文字右侧或弹窗中，具体取决于显示设置。快捷键：**C** 原文、**V** 原文说明、**B** 译文、**N** 译文说明、**M** 图片；**空格键**开始或前进。

启动会话时可以选择初始显示设置；默认显示设置也保存在应用设置中。键盘快捷键在输入框等控件获得焦点时不会触发。

## 会话顺序和保存

词条顺序由排序方式决定：“随机”会在重置顺序时打乱，“按字母排序”依据原文，“原始顺序”依据导入顺序。之后会话沿着该顺序逐项进行。会话状态保存在本地，应用重新打开后可以恢复活动会话。
