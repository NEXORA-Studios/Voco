# 词汇包

Voco 将一组词汇保存为一个词汇包。在词汇包列表中，可以新建、编辑名称和说明、指定一个分类（Bundle）、选择词条顺序、开始会话、重置顺序或删除词汇包。

## 导入 Excel 工作簿

导入向导支持 `.xlsx` 和 `.xls`。一个工作簿可以包含多个工作表，导入时先选择需要的工作表。Voco 会预览工作表，并提供检测到的表头行、无表头（从第一行读取）和自定义起始行选项。

需要映射原文和译文列；也可以映射原文说明、译文说明和图片列。原文或译文缺少任一项的行不会加入词汇包。保存前可以核对工作表和列映射。

图片可以来自图片列、从工作簿图片中按锚定列提取，也可以在导入流程中选择图片文件或文件夹进行匹配。图片资源会随词汇包保存在本地。工作簿的任意格式、公式或其他功能不会因此自动导入。

## 词汇包选项

创建词汇包时，可设置名称、可选说明、分类和排序方式：

- **随机**：重置词汇包顺序时打乱词条。
- **按字母排序**：按原文排序。
- **原始顺序**：保留导入时的顺序。

这些选项决定会话中的词条顺序，并不是不同的课堂游戏模式。编辑页面会保存词汇包信息，并支持行内编辑、删除、追加导入、重新导入和清空词条。创建和导入词汇内容使用导入向导。

## 分类和本地文件

一个词汇包可归属一个分类。主页按分类标签页分组显示词汇包，也会显示未分类组。应用将数据保存在本地应用数据目录中。当前界面没有词汇包导出功能；若要保留可移植的源文件，请另行保存原始工作簿。手动修改文件前请备份整个应用数据目录。
