# 随机抽取器

随机抽取器是独立工具，不同于词汇会话。它使用你在“随机抽取器”页面创建的预设。每个预设包含名称和标签列表；每个标签在预设耗尽前可以被抽取一次或指定次数。

## 创建预设

选择“新建预设”，输入名称，每行填写一个标签。若要允许某项被抽取多次，在标签后加上 `::` 和次数：

```text
小明
小华::2
小丽
```

示例中“小明”和“小丽”各有一次可抽取次数，“小华”有两次。无效或小于 1 的次数会按 1 处理。空行会忽略；预设必须有名称且至少包含一个标签。

每个预设中的标签应保持唯一。剩余次数按标签文本记录，重复标签不会被视为独立项目。

## 抽取和重置

选择预设后启动抽取动画；准备好时可以停止，动画也会在短时间后自动停止。每次选中都会消耗一次次数。所有次数用完后会显示已耗尽。选择“重置”可恢复当前预设的配置次数。

可以在预设列表中编辑或删除预设。预设保存在本地。此工具不会从词汇包中抽取词条；词汇学习请使用词汇会话。
