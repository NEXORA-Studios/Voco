# 开始使用 Voco

Voco 是一款桌面词汇应用。主要流程是从 Excel 工作簿创建词汇包，再在会话中依次展示词条。

## 1. 创建词汇包

在“词汇包”页面选择“新建词汇包”，填写名称、可选说明、分类和排序方式。进入 Excel 导入步骤后，选择 `.xlsx` 或 `.xls` 工作簿。

## 2. 映射工作簿内容

选择工作表、表头行或数据起始行，再映射**词汇**和**翻译**列；**简介**、**简介翻译**和**例图**列为可选项。检查预览和图片匹配后保存词汇包。

**词汇**或**翻译**任一为空的行会被跳过。词汇包保存在本地；当前界面没有导出词汇包的功能。

## 3. 开始词汇会话

从词汇包卡片启动会话。每个词条展示前会播放切换动画，然后按词汇包顺序显示。可以通过显示控件开关**词汇**、**简介**、**翻译**、**简介翻译**和**例图**。按**空格键**开始或前进。

顺序由词汇包的排序方式决定：随机、按原文排序或原始顺序。“随机”会在重置词汇包顺序时打乱列表，不会在每次前进时重新随机挑选词条。

## 随机抽取器是另一个工具

随机抽取器用于用户自定义的标签列表，例如学生姓名。预设可设置每个标签的抽取次数，与词汇包及词汇会话相互独立。
