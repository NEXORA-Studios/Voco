# 隨機抽選器

隨機抽選器是獨立工具，與詞彙課程不同。它使用你在「隨機抽選器」頁面建立的預設。每個預設包含名稱和標籤清單；預設耗盡前，每個標籤可抽選一次或指定次數。

## 建立預設

選擇「新增預設」，輸入名稱，每行填寫一個標籤。若要允許某項抽選多次，請在標籤後加上 `::` 和次數：

```text
小明
小華::2
小麗
```

範例中「小明」和「小麗」各有一次可抽選次數，「小華」有兩次。無效或小於 1 的次數會以 1 計算。空白列會忽略；預設必須有名稱且至少包含一個標籤。

每個預設中的標籤應保持唯一。剩餘次數依標籤文字記錄，重複標籤不會被視為獨立項目。

## 抽選與重設

選擇預設後啟動抽選動畫；準備好時可以停止，動畫也會在短時間後自動停止。每次選中會消耗一次次數。所有次數用完後會顯示已耗盡。選擇「重設」即可恢復目前預設的設定次數。

可以在預設清單中編輯或刪除預設。預設儲存在本機。此工具不會從詞彙包抽選詞條；詞彙練習請使用詞彙課程。
