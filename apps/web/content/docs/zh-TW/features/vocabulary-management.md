# 詞彙包

Voco 將一組詞彙儲存為一個詞彙包。在詞彙包清單中，可以新增、編輯名稱和說明、指定一個分類（用於首頁分組）、選擇詞條順序、開始課程、重設順序或刪除詞彙包。

每個詞條由五個部分組成：

- **詞彙**：原文單字或短語。
- **簡介**：原文詞彙的補充說明。
- **翻譯**：對應的譯文單字或短語。
- **簡介翻譯**：對譯文的補充說明。
- **例圖**：與詞條關聯、可在課程中顯示的圖片。

## 匯入 Excel 活頁簿

匯入精靈支援 `.xlsx` 和 `.xls`。一個活頁簿可以包含多個工作表，匯入時先選擇需要的工作表。Voco 會預覽工作表，並提供偵測到的標題列、無標題（從第一列讀取）和自訂起始列選項。

必須對應**詞彙**和**翻譯**欄位；也可以對應**簡介**、**簡介翻譯**和**例圖**欄位。詞彙或翻譯任一項缺漏的資料列不會加入詞彙包。儲存前可以核對工作表和欄位對應。

例圖可以來自例圖欄位、從活頁簿圖片中依錨定欄擷取，也可以在匯入流程中選取圖片檔案或資料夾進行配對。圖片資源會隨詞彙包儲存在本機。活頁簿的任意格式、公式或其他功能不會因此自動匯入。

## 詞彙包選項

建立詞彙包時，可設定名稱、選填說明、分類和排序方式：

- **隨機**：重設詞彙包順序時打亂詞條。
- **依字母排序**：依詞彙內容排序。
- **原始順序**：保留匯入時的順序。

這些選項決定課程中的詞條順序，並不是不同的課堂遊戲模式。編輯頁面會儲存詞彙包資訊，並支援行內編輯、刪除、追加匯入、重新匯入和清空詞條。建立與匯入詞彙內容請使用匯入精靈。

## 分類與本機檔案

一個詞彙包可歸屬一個分類。首頁依分類索引標籤分組顯示詞彙包，也會顯示未分類群組。應用程式將資料保存在本機應用程式資料目錄。目前介面沒有詞彙包匯出功能；若要保留可攜式來源檔，請另外保存原始活頁簿。手動修改檔案前請備份整個應用程式資料目錄。
