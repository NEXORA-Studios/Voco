# 詞彙課程

從詞彙包卡片啟動課程。Voco 依照詞彙包設定的順序逐項顯示詞條，選擇下一項時會播放動畫。動畫是切換效果，不會自行隨機挑選新詞條。若要隨機排列整組詞彙，請將排序方式設為「隨機」並重設順序。

## 課程流程

1. 從首頁啟動一個詞彙包。
2. 按**空白鍵**或課程按鈕開始詞條切換動畫。
3. 動畫停止後查看目前詞條，並依需要顯示答案或相關內容。
4. 再按空白鍵或下一項按鈕繼續。
5. 完成後，可選擇排序方式重新開始，或返回詞彙包清單。

課程會顯示剩餘詞條數。課程開始時，缺少原文或譯文的詞條會排除。

## 顯示控制

課程控制項可開關原文、原文說明、譯文、譯文說明和圖片。圖片可顯示於文字右側或對話框中，依顯示設定而定。快速鍵：**C** 原文、**V** 原文說明、**B** 譯文、**N** 譯文說明、**M** 圖片；**空白鍵**開始或前進。

啟動課程時可以選擇初始顯示設定；預設顯示設定也會儲存於應用程式設定中。輸入欄位等控制項取得焦點時，不會觸發鍵盤快速鍵。

## 課程順序與儲存

詞條順序由排序方式決定：「隨機」會在重設順序時打亂，「依字母排序」依原文排序，「原始順序」依匯入順序排列。課程接著會依序前進。課程狀態儲存在本機，重新開啟應用程式後可以還原進行中的課程。
