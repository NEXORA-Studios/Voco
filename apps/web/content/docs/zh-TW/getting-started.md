# 開始使用 Voco

Voco 是一款桌面詞彙應用程式。主要流程是從 Excel 活頁簿建立詞彙包，再於課程中依序顯示詞條。

## 1. 建立詞彙包

在「詞彙包」頁面選擇「新增詞彙包」，填寫名稱、選填說明、分類與排序方式。進入 Excel 匯入步驟後，選擇 `.xlsx` 或 `.xls` 活頁簿。

## 2. 對應活頁簿內容

如果活頁簿包含多個工作表，先選擇要匯入的工作表。選擇標題列或資料起始列，再對應**詞彙**與**翻譯**欄位；**簡介**、**簡介翻譯**和**例圖**為選填。檢查預覽和圖片配對後儲存詞彙包。

**詞彙**或**翻譯**任一欄為空的資料列會略過。詞彙包儲存在本機；目前介面沒有匯出詞彙包的功能。

## 3. 開始詞彙課程

從詞彙包卡片啟動課程。每個詞條顯示前會播放切換動畫，接著依詞彙包順序顯示。可使用顯示控制開關**詞彙**、**簡介**、**翻譯**、**簡介翻譯**和**例圖**。按**空白鍵**開始或前進。

順序由詞彙包的排序方式決定：隨機、依原文排序或原始順序。「隨機」會在重設詞彙包順序時打亂清單，不會在每次前進時重新隨機挑選詞條。

## 隨機抽選器是另一項工具

隨機抽選器用於自訂標籤清單，例如學生姓名。預設可以設定每個標籤的抽選次數，與詞彙包及詞彙課程彼此獨立。
