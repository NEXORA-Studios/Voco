# Excel 匯入參考

目前詞彙包精靈支援 `.xlsx` 和 `.xls` 活頁簿。應用程式介面沒有提供 CSV 匯入選項。

## 活頁簿與工作表

可透過檔案選擇器或拖放方式選擇活頁簿。若檔案包含多個工作表，可在工作表選擇器中選擇要匯入的工作表。預覽會顯示工作表資料及合併儲存格資訊。

## 資料列與欄位對應

精靈會偵測前五列中的候選標題列，也提供無標題（從第一列開始）和自訂起始列。**詞彙**與**翻譯**欄位為必要對應；**簡介**、**簡介翻譯**及**例圖**欄位則為選填。

只有**詞彙**和**翻譯**皆非空的資料列會加入，文字前後空白會移除。**簡介**和**簡介翻譯**從對應欄位讀取；**例圖**欄位可用來配對圖片資源。

## 圖片

匯入流程可以依所選工作表和錨定欄擷取活頁簿內嵌圖片，也可以載入外部圖片檔案或資料夾並配對至詞條。外部圖片支援 PNG、JPEG、GIF、WebP 和 BMP。請在課程中確認圖片顯示正常。

## 儲存前檢查

儲存前請檢查工作表、資料起始列、欄位對應和預覽。**詞彙**或**翻譯**任一欄為空的資料列會略過。Voco 不保證保留活頁簿格式、公式、批註或所有 Excel 功能。
