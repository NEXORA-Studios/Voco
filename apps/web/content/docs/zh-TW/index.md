# Voco 文件

以下指南對應目前桌面應用程式的實際功能：從 Excel 建立詞彙包、依序進行詞彙課程、使用獨立的隨機抽選器，以及將舊版 YAML 資料自動遷移至目前的 TOML 格式。

## 文件導覽

- [快速開始](/docs/getting-started)：從 Excel 活頁簿建立詞彙包並開始詞彙課程。
- [詞彙包](/docs/features/vocabulary-management)：分類、排序、活頁簿匯入與本機儲存。
- [詞彙課程](/docs/features/classroom-challenge)：詞條順序、顯示控制、快速鍵與課程狀態。
- [隨機抽選器](/docs/features/random-picker)：建立標籤預設，並設定每個標籤重設前可抽選的次數。
- [Excel 匯入參考](/docs/reference/import-format)：支援的活頁簿格式、工作表選擇、欄位對應與圖片處理。
- [舊資料遷移](/docs/migration/from-legacy)：已實作的 YAML 資料啟動遷移流程。

文件只描述應用程式中已實作的行為。對於目前介面不支援的功能，例如匯出詞彙包或手動遷移／還原介面，會明確說明其限制。
