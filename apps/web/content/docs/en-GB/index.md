# Voco documentation

These guides describe the current desktop application: Excel-based vocabulary package creation, ordered vocabulary sessions, a separate Random Picker, and the automatic migration from the legacy YAML data layout.

## Guides

- [Getting started](/docs/getting-started): create a package from an Excel workbook and start a vocabulary session.
- [Vocabulary packages](/docs/features/vocabulary-management): package categories, sorting, workbook import, and local storage.
- [Vocabulary sessions](/docs/features/classroom-challenge): entry order, display controls, keyboard shortcuts, and session state.
- [Random Picker](/docs/features/random-picker): create label presets and configure how many times each label may be picked before reset.
- [Excel import reference](/docs/reference/import-format): supported workbook formats, worksheet selection, mappings, and image handling.
- [Legacy data migration](/docs/migration/from-legacy): the implemented startup conversion from YAML data to the current TOML layout.

The documentation focuses on behavior present in the application. Where the interface does not provide a capability, such as package export or a manual migration/restore screen, the guides state that limitation.
